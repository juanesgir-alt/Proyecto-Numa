# Exploraciones visuales — dirección que gustó

Se exploraron tres piezas en la línea ilustrada y colorida de NUMA: 
- «Tu idea merece algo más que un logo».
- «Así trabajamos en NUMA».
- «Proyectos que toman forma».

El usuario prefirió esta versión visual enriquecida (ilustraciones, recortes, iconos y énfasis tipográficos) frente a las plantillas simples generadas anteriormente.

**Cuidado:** las exploraciones son referencias y no archivos maestros definitivos, especialmente cuando la IA reproduce un logo o imágenes de proyectos. Antes de publicar, sustituir o revisar elementos con recursos originales.
