# NUMA Creative Studio

Repositorio oficial de trabajo de **NUMA Creative Studio**, independiente de `juanesgir-alt/Portafolio-2026`. Los materiales de NUMA se organizan aquí y **no se modifica el repositorio del portafolio**.

**Mercado prioritario:** Colombia (Bogotá, Medellín, Cali); expansión remota a Latinoamérica.  
**Idioma comercial:** español.  
**Lema:** Ideas que toman forma.

## Estructura

- `00_MARCA/`: directrices visuales, referencias, logotipos raster y recursos de identidad.
- `01_PLANIFICACION/`: posicionamiento, calendario de 12 posts, guiones y captación.
- `02_INSTAGRAM/`: publicaciones, exploraciones aprobadas y decisiones de diseño.
- `03_PROSPECTOS/`: investigación de potenciales clientes colombianos.
- `04_HISTORIAL/`: registro de avances, entregas y pendientes.

## Identidad y sistema visual

Principios: **simple · expresivo · positivo · flexible**. Idea rectora: **«Ideas que toman forma»**.

Paleta oficial: carbón `#0F1014`, violeta `#8C67F7`, verde `#2AA990`, crema `#F4F3EC`, amarillo `#FFD43A` y coral `#FD6333`.

**Tipografías vigentes:** Clash Grotesk Bold para titulares y DM Sans Regular / Medium para textos. Las menciones anteriores a Clash Display / Manrope quedan como referencias previas.

El logo debe proceder del recurso original; nunca reconstruirlo escribiendo “NUMA” con una fuente. El archivo `00_MARCA/LOGOS_Y_SIMBOLOS/NUMA_KIT_LOGOS_RASTER.zip` contiene recortes y variantes raster, no un master vectorial. Si se obtiene el SVG/AI oficial, usarlo en producción.
