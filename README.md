# NUMA Creative Studio

Repositorio oficial de trabajo de **NUMA Creative Studio**, independiente de `juanesgir-alt/Portafolio-2026`. Los materiales de NUMA se organizan aquí y **no se modifica el repositorio del portafolio**.

**Mercado prioritario:** Colombia (Bogotá, Medellín, Cali); expansión remota a Latinoamérica.  
**Idioma comercial:** español.  
**Lema:** Ideas que toman forma.

## Estructura
- `00_MARCA/`: directrices visuales, referencias y recursos de identidad.
- `01_PLANIFICACION/`: posicionamiento, calendario de 12 posts, guiones y captación.
- `02_INSTAGRAM/`: publicaciones, exploraciones aprobadas y decisiones de diseño.
- `03_PROSPECTOS/`: investigación de potenciales clientes colombianos.
- `04_HISTORIAL/`: registro de avances, entregas y pendientes.

## Diseño aprobado
Referencias originales: logo orgánico de NUMA con símbolo floral/asterisco, tipografía expresiva, ilustración amigable, recortes, iconos sólidos redondeados, jerarquías tipográficas fuertes y formas orgánicas fluidas. **Nunca sustituir el logo maestro con un logotipo generado.**

Paleta: `#0F1014` carbón · `#8C67F7` violeta · `#2AA990` verde · `#F4F3EC` crema · `#FFD43A` amarillo · `#FD6333` coral. Tipografías mencionadas en los materiales: Clash Display / Manrope; las láminas de referencia recientes también muestran Clash Grotesk / DM Sans. Confirmar tipografías maestras antes del arte final.
