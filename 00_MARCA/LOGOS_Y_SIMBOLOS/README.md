# Logotipos, símbolo y paleta — recursos raster

Descarga y extrae `NUMA_KIT_LOGOS_RASTER.zip` para obtener el recorte del logotipo de referencia, variantes transparentes raster, símbolo floral/asterisco, paleta y archivo de instrucciones.

**Importante:** las variantes transparentes son extracciones raster, no un archivo vectorial maestro. No redibujar ni sustituir el wordmark con texto de una fuente. Si se obtiene el SVG/AI oficial, priorizar ese archivo.
